# Advance development to 0.5.0

## Why

The ten-improvement batch follows the merged 0.4.0 development baseline and
needs its own version and compatibility guidance.

## What Changes

- Set development and plugin metadata to 0.5.0.
- Rebuild app identity from the shared version source.
- Document ten improvements without changing historical release evidence.

## Impact

No dependency, archive schema, publication, or release-process change.
Fallback builds report `v0.5.0-dev`. See ADR 0019.
